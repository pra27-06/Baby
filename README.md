# 🌙 Pip the Skull Baby · Junior Dream Engineer
> **“I build the dreams you fall asleep inside.”**
>
> Official Track 1 Submission for **haX.baby’s “Baby’s First Website” Hackathon** (17–19 October 2026).

---

## 🌟 Overview & Character Profile

- **Name:** Pip
- **Species:** Sleepy Skull Baby (Smooth round skull, glowing warm amber eye sockets, tiny crooked grin, starry bedtime nightcap with a pink bow).
- **Profession:** Junior Dream Engineer at **Midnight Nursery**.
- **Role:** Designing celestial lullabies, glowing bedside nightlights, and soothing bedtime stories to help the neighborhood's little creatures fall asleep.
- **Tone:** 100% gentle, cozy, and cute (never scary or creepy!).

---

## 🧸 The 3 Showcase Projects

1. **The Lullaby Lab & Music Box**
   - An interactive pentatonic music box (C4, D4, E4, G4, A4, C5) synthesized directly in real time using the **Web Audio API** (zero external MP3 dependencies).
   - Features winding crank physics, keyboard shortcuts (`1-6`), and an automatic starlight cascade.
2. **The Nightlight Collection**
   - A curated gallery of handcrafted bedside beacons (*Crescent Moon Porcelain*, *Stardust Firefly Jar*, *Midnight Aurora Bell*).
   - Features real-time interactive brightness dimmer adjusting ambient room luminescence.
3. **Dream Delivery Routes**
   - An interactive SVG rooftop flight radar tracking Pip’s nightly deliveries across neighborhood chimneys.
   - Clickable delivery waypoints with real-time dispatch logs.

## 🛠️ Tech Stack & Clean Craft

- **Framework:** Next.js 16 (App Router) + React 19 + TypeScript
- **Styling:** Tailwind CSS v4 + Editorial Typography (`Fraunces` & `Fredoka`)
- **Audio:** Native Web Audio API (`AudioContext`, `OscillatorNode`, exponential gain envelopes)
- **Effects:** `canvas-confetti`, `lucide-react`
- **Performance:** 100% zero-console errors, mobile-responsive layout, and instant page loads.
